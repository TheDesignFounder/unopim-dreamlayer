## Description

DreamLayer brings image creation and editing into UnoPim. Select product images, describe what you want to change, and review the results before saving anything to your catalog.

Keep refining the same image through follow-up instructions. Change a background, try a different setting, or remove the background entirely. DreamLayer chooses from its image models for the task, while the product and image destination stay attached to the result.

For several products, give one instruction and review a separate preview for each image. You decide which results to apply. UnoPim continues to manage your product information and permissions.

The image editor works without UnoPim's native AI chat. An optional native chat connection is available only on hosts that include the required extension hooks. Availability is checked automatically.

## Data sharing

Image editing sends the selected image or previous preview, editing instructions, requested image dimensions and request identifiers to DreamLayer. Optional chat assistance also sends the messages and recent conversation supplied in the editor. Account connection sends the installation name, identifier and settings URL. Requests use your access credential. DreamLayer and its processing providers receive the data needed to process requests.

The extension does not upload the whole catalog, switch the host's default AI provider or enable history for other providers. Optional editor conversation saving is off by default. UnoPim retains private previews and job records needed for recovery and explicit Apply.
